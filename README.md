<summary><b>📱 变成桌面 App（点开收起你的系统）</b></summary>

打开网页后，把它「添加到主屏幕」，下次就能像 App 一样从桌面点开，全屏、没浏览器那圈地址栏。

**🍎 iOS（Safari）**
1. 用 **Safari** 打开（Chrome / 微信里打开都不行，必须 Safari）
2. 底部点 **分享图标**（方框向上的箭头 ↑）
3. 滑动找到 **「添加到主屏幕」** → 添加
4. 桌面出现「暗标」图标，点开即全屏

**🤖 安卓（Chrome）**
1. 用 **Chrome** 打开
2. 右上角 **⋮** → **「添加到主屏幕」**（或「安装应用」）
3. 桌面出现图标，点开独立窗口运行

> 微信内打开的，先点右上角 **⋯** → **在浏览器中打开**，再按上面步骤操作。
