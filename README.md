> 把某时某地说不清的那几秒，留在原地——等一个路过的人翻到。

<br>

一张图，一个坐标，寥寥数语。点一下，它就被投了出去——没有账号，没有登录，没有谁在后台盯着你的措辞。每个人都是匿名的，每一条都是一次投放。

路过的人只看到一枚化名、一抹渐变色。**不足以指认你，却足以让同一双眼睛在第二次相遇时被认出来。**

### ⌖　路过

新的会自己冒出来。

不用一直盯着——它每过一会儿悄悄看一眼有没有人新留下什么，下拉能马上拉来最新的。按城市筛，看别处的人都留下了什么。

</td>
</tr>

### ⊕　靠近

点开任意一条，一键跳进地图，走到那个坐标去。

### ✎　回声

在别人留下的下面，说点什么。

不多说。每天几句，每句不长——够把意思递过去，不够说满。

### ◍　认出自己

「我的」只给你看：一枚化名，一串掩了码的痕迹，你投下的、还剩的。

清了缓存也不怕。化名会从同一处痕迹里长回同一个——**你以为抹掉了，但它认得你的形状。**
